# Interactive Kiosk Monorepo

고객의 셀프 주문과 점주의 매장 운영을 연결하는 카페 키오스크 프로젝트입니다.
고객은 키오스크에서 메뉴를 선택하고 주문하며, 점주는 관리자 웹에서 주문 진행 상황과 판매내역을 확인합니다.

## 프로젝트 구성

| 구성 | 사용자 | 역할 |
| --- | --- | --- |
| 고객 키오스크 | 매장 방문 고객 | 매장·포장 선택, 메뉴 탐색, 장바구니, 주문 접수 |
| 점주 관리자 웹 | 가게 주인 | 주문 확인·처리, 결제 확인, 판매내역·매출 조회 |
| 공통 API 서버 | 고객 앱과 관리자 웹 | 메뉴 제공, 주문 저장, 인증, 판매 집계 |

고객 키오스크는 Android 태블릿에서 실행하는 Flutter 앱을 목표로 개발합니다. 현재 저장소에는 주문 흐름을 확인할 수 있는 웹 프로토타입이 있으며, Flutter 앱 구현은 예정되어 있습니다. 점주 화면은 웹으로 유지합니다.

## 주요 기능

### 고객 키오스크

- 매장 이용·포장 주문 선택
- 커피·라떼, 스무디, 티 카테고리별 메뉴 탐색
- 큰 글씨 모드와 화면 하단에 고정된 장바구니
- 메뉴 수량 조절, 주문 금액 확인, 주문 번호 발급
- 얼굴 사진과 저장된 날씨 정보를 활용한 선택형 메뉴 추천

### 점주 관리자 웹

- 관리자 로그인
- 날짜·상태별 주문 목록과 주문 상세 조회
- 주문 접수 → 준비 중 → 완료 상태 관리
- 카운터 결제 확인 및 미결제 주문 취소
- 기간별 매출, 일별 판매내역, 메뉴별 판매량 조회

### 주문 데이터 관리

- 서버의 메뉴 가격을 기준으로 주문 금액 계산
- 주문 시점의 메뉴 이름·단가·수량 보존
- 동일한 주문 요청을 재전송할 때 중복 저장 방지
- 결제 확인된 주문을 기준으로 매출 집계

## 서비스 이용 흐름

1. 고객이 키오스크에서 매장 또는 포장을 선택합니다.
2. 메뉴와 수량을 선택하고 주문을 접수합니다.
3. 서버가 주문을 저장하고 고객에게 주문 번호를 안내합니다.
4. 점주가 관리자 웹에서 주문과 카운터 결제를 확인합니다.
5. 음료 준비 후 주문을 완료하고 판매내역을 확인합니다.

현재 결제는 카운터에서 진행하며, 관리자 웹에서 결제 완료를 기록합니다. 결제 단말기·PG 및 자동 환불 연동은 아직 포함하지 않습니다.

## 기술 구성

| 영역 | 현재 사용 기술 | 개발 방향 |
| --- | --- | --- |
| 고객 화면 | HTML · CSS · JavaScript | Flutter 기반 Android 태블릿 앱 |
| 점주 웹 | HTML · CSS · JavaScript | 웹 기반 매장 운영 화면 |
| 백엔드 | Python · FastAPI · Pydantic | 고객 앱과 관리자 웹의 공통 API |
| 데이터베이스 | SQLite | 메뉴·주문·판매 데이터 저장 |
| 사진 분석 | DeepFace (선택 설치) | 연령대 기반 메뉴 추천 |

## 저장소 구조

```text
apps/
  frontend-app/kiosk/   고객용 키오스크 프로토타입
  frontend-web/admin/  점주 관리자 웹
  backend/             FastAPI 서버, DB, 메뉴 이미지, 테스트
scripts/               로컬 실행·검증 스크립트
.github/               PR 템플릿
```

## 시작하기

Windows 개발 환경에서 백엔드를 실행하면 고객 프로토타입과 점주 웹을 함께 확인할 수 있습니다.

- 고객 화면: `http://127.0.0.1:8000/kiosk`
- 점주 웹: `http://127.0.0.1:8000/admin`
- API 문서: `http://127.0.0.1:8000/docs`

저장소 루트에서 다음 명령으로 개발 서버를 실행합니다.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r apps/backend/requirements.txt
Copy-Item apps/backend/.env.example apps/backend/.env
# 생성한 .env에서 ADMIN_PASSWORD를 설정하세요. 기존 .env가 있으면 복사하지 않습니다.
.venv\Scripts\python.exe -m uvicorn app:app --app-dir apps/backend --host 127.0.0.1 --port 8000 --reload
```

개인 작업 계획과 상세 개발 메모는 로컬 `docs/`에서 관리하며 Git에 포함하지 않습니다.
커밋과 PR 작성 규칙은 [기여 가이드](CONTRIBUTING.md)에 정리되어 있습니다.
